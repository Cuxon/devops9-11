# Журнал типовых инцидентов

Ниже описаны учебные сценарии, а не журнал уже выполненных запусков GitHub.

| Инцидент | Симптом | Причина и исправление |
|---|---|---|
| Неиспользуемая переменная | W0612 в Static analysis | Удалить неиспользуемую `details`; не отключать правило |
| Недостаточные права | build успешен, deploy не получает OIDC | Добавить `id-token: write` к `pages: write` |
| Битая ссылка | Build documentation завершается ошибкой | Заменить отсутствующий recovery.md на incidents.md |
| Прежняя страница при успешном deploy | Версия не совпадает с ожидаемой | Проверить URL, SHA в build.txt и кэш |

## Правило разбора

Зафиксируйте симптом, компонент, строку журнала, причину, исправление и проверку восстановления.
При отказе build новое содержимое не передаётся в deploy, предыдущая публикация сохраняется.
