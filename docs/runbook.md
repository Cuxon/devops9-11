# Эксплуатация

## Штатная публикация

1. Убедитесь, что проверка `pylint` в Pull Request успешна.
2. Выполните слияние в `main`.
3. Откройте Actions → Publish documentation.
4. Дождитесь успеха заданий `build` и `deploy`.
5. Откройте URL окружения `github-pages` и проверьте версию на главной странице.

## Ручной перезапуск

Используйте Actions → Publish documentation → Run workflow.
Повторный запуск старого коммита использует старые исходники и не исправляет дефекты.

## Диагностика

Определите отказавший этап: CI, сборка, загрузка артефакта или публикация.
Читайте журнал конкретного шага и сопоставляйте SHA с ожидаемым коммитом.
При успешном deploy и старой странице проверьте URL, кэш браузера и `build.txt`.

## Восстановление

Перед восстановлением изучите [инструкцию по аварийному восстановлению](recovery.md).
